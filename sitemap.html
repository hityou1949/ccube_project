자기소개 페이지 사이트맵

이 프로젝트는 페이지가 하나뿐인 단일 페이지 사이트입니다. 그래서 여기서 말하는 "사이트맵"은 여러 페이지 간 이동이 아니라, 헤더에서 클릭했을 때 한 페이지 안에서 어느 순서·위치의 섹션으로 이동하는지를 보여주는 앵커(#) 내비게이션 지도입니다.

아래 그림은 헤더의 배치 순서(위)와 실제 문서에서 섹션이 쌓인 순서(아래)를 화살표로 연결해 보여줍니다.

!

표기 중복: 헤더 왼쪽의 로고("자기소개", #intro로 이동)와 메뉴의 두 번째 항목("자기소개", #about로 이동)이 똑같은 문구를 쓰지만 서로 다른 섹션으로 이동합니다. 방문자가 로고를 "자기소개 섹션으로 가는 링크"로 오해할 수 있는 지점입니다.
