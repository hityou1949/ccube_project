# ccube_project — 자기소개 페이지

HTML과 CSS만으로 만드는 **중학생 자기소개 웹 페이지** 프로젝트입니다.  
소개, 관심사, 목표, 학습 내용을 한 페이지에 담아 웹 개발 기초를 익히는 것을 목표로 합니다.

---

## 작업 목표

1. **시맨틱 HTML 구조 익히기**  
   `header`, `nav`, `main`, `section`, `footer` 등 의미 있는 태그로 페이지를 구성합니다.

2. **CSS로 레이아웃·디자인 구현하기**  
   CSS 변수(디자인 토큰), Flexbox, 반응형 스타일을 활용해 읽기 쉬운 페이지를 만듭니다.

3. **접근성·사용성 고려하기**  
   본문 바로가기 링크, ARIA 레이블, 키보드 탐색이 가능한 내비게이션 등 기본적인 웹 접근성을 적용합니다.

4. **모듈형 CSS 구조 연습하기**  
   `tokens`, `base`, `layout`, `components`로 스타일을 분리해 유지보수하기 쉬운 구조를 만듭니다.

5. **공개 저장소에 안전하게 올리기**  
   아래 **민감 정보 제외 규칙**을 지키며, 개인정보 없이 학습용 콘텐츠만 포함합니다.

---

## 기술 스택

| 구분 | 사용 기술 | 비고 |
|------|-----------|------|
| 마크업 | **HTML5** | 시맨틱 태그, 한국어(`lang="ko"`) |
| 스타일 | **CSS3** | 변수, Flexbox, `@import` 모듈 분리 |
| 폰트 | Pretendard GOV (CDN) | 가독성을 위한 웹폰트 (HTML `<link>`로 로드) |

> **사용하지 않는 기술:** JavaScript, 프레임워크(React 등), 빌드 도구, 백엔드 서버  
> 본 프로젝트는 **HTML + CSS만**으로 동작합니다.

---

## 프로젝트 구조

```
ccube_project/
├── index.html          # 메인 페이지
├── css/
│   ├── main.css        # 스타일 진입점 (@import)
│   ├── tokens.css      # 색상·간격·타이포 등 디자인 토큰
│   ├── base.css        # 리셋·기본 요소 스타일
│   ├── layout.css      # 헤더·푸터·그리드·섹션 레이아웃
│   └── components.css  # 카드·태그·취미 목록 등 UI 컴포넌트
└── README.md
```

## 실행 방법

1. 저장소를 클론하거나 파일을 다운로드합니다.
2. `index.html`을 브라우저에서 직접 엽니다.  
   (별도 설치·빌드 없이 로컬에서 바로 확인 가능합니다.)

## 민감 정보 제외 규칙

공개 Git 저장소에 올릴 때 아래 항목은 **절대 포함하지 않습니다.**

### 포함 금지 항목

| 분류 | 예시 |
|------|------|
| 신원 정보 | 실명, 별명(식별 가능한 경우), 생년월일, 학번 |
| 연락처 | 전화번호, 이메일, SNS 계정·URL, 메신저 ID |
| 위치 정보 | 집 주소, 학교명·반·동아리 등 소속으로 특정 가능한 정보 |
| 미디어 | 본인·친구·가족이 식별 가능한 사진·영상 |
| 계정·보안 | 비밀번호, API 키, 토큰, `.env` 등 인증 정보 |

### 작성·커밋 시 지침

- 자기소개 문구는 **일반적인 예시 문장** 또는 **가명·역할 표현**(예: "중학생", "학습자")을 사용합니다.
- 실제 정보가 필요한 경우는 **로컬에서만** 수정하고, Git에 커밋·푸시하지 않습니다.
- 실수로 민감 정보를 커밋했다면, 히스토리에서 완전히 제거한 뒤 다시 푸시합니다. (단순 삭제 커밋만으로는 부족할 수 있습니다.)
- `.gitignore`에 `.env`, `secrets/` 등 민감 파일 패턴을 추가해 두는 것을 권장합니다.
